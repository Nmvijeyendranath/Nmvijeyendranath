## 🧠 Featured Project: JARVIS-Style AI Assistant

A personal assistant that combines an LLM with retrieval over my own knowledge and a set of callable tools. Here's the architecture I'm working towards:

```mermaid
flowchart LR
    U([🎤 User Input<br/>Text / Voice]) --> R{Intent<br/>Router}
    R -->|Question| RAG[📚 RAG Pipeline]
    R -->|Action| T[🛠️ Tool Executor]
    RAG --> V[(Vector<br/>Database)]
    V --> RAG
    RAG --> L[🧠 LLM Core]
    T --> L
    L --> O([💬 Response / Action])
    O -.->|memory| M[(Conversation<br/>Memory)]
    M -.-> R

    style L fill:#0f766e,color:#fff,stroke:#2dd4bf
    style V fill:#1e3a8a,color:#fff,stroke:#60a5fa
    style M fill:#1e3a8a,color:#fff,stroke:#60a5fa
```

**Highlights:** retrieval-augmented answers · tool calling · conversational memory · modular design so each component can be swapped or tested independently.
